## 🔭 What I'm Working On Right Now

### 📊 Istanbul Airbnb Market Analysis *(in progress)*

I'm starting an end-to-end data analysis project on short-term rental listings in Istanbul, using the public listings data from [Inside Airbnb](http://insideairbnb.com/get-the-data/).

**Questions I want to answer**
- What actually drives nightly price: neighbourhood, room type, capacity, amenities, or host type?
- Which neighbourhoods are over- or under-priced compared with similar listings?
- How do availability, reviews, and pricing change across the year?
- Do hosts with multiple listings behave differently from single-listing hosts?

**Planned workflow**
- [ ] Download and document the raw data (listings, calendar, reviews)
- [ ] Clean it with Python (Pandas, NumPy): nulls, price formatting, duplicates, outliers
- [ ] Load into a SQL database and write the analysis queries
- [ ] Exploratory data analysis with charts and summary statistics
- [ ] Simple pricing model to identify the strongest price drivers
- [ ] Interactive dashboard in React + Recharts
- [ ] Write a short business-style findings memo with recommendations

**Stack:** Python (Pandas, NumPy), SQL, React, Recharts
**Repo:** *coming soon*
